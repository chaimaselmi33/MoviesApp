# MoviesApp
# About this project
This is a movie streaming application powered by Angular for the front end and Spring Boot for the back end, with self-designed interfaces created using Figma. The app simulates features of modern movie streaming platforms, including browsing, searching, and viewing movie details.
### Preview
![preview](https://user-images.githubusercontent.com/69457494/222967497-552eec53-daba-4849-b848-17b9e0e2bd0a.jpg)
# Features
The user can:
- Diplay the list of all movies (Pagination included)
- Display movies by category
- Display movie details
- Search a movie by its title
# How To Run
## Client-Side App
1- Install the app dependencies
To install app dependencies run:\
`npm install`\
2- Run the project
To start developement server on http://127.0.0.1:4200 run:\
`ng serve`\
## Server-Side App
To run the springboot application open the project in eclipse IDE then run the main class.
